# Document Studio - Project Hub

## Status

Planning and architecture re-audit complete. Ready to create a private repository and start Phase 0 in Codex.

## Canonical decisions

- Product name: Document Studio.
- Desktop first: Windows, then macOS.
- Local-first processing and no network requirement for core tools.
- Tauri/React/Rust desktop architecture.
- One verified operation contract for every tool.
- UI direction: Precision Paper.
- Optional web/mobile and AI only after the desktop core is stable.
