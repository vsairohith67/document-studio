# Import Document Studio into Notion

## Recommended approach

1. Create a private page named **Document Studio - Project Hub**.
2. Import the numbered Markdown files in this folder in order, or drag the full folder into Notion's Markdown import.
3. Import `01-Feature-Catalogue.csv` as a database.
4. Upload the files in `attachments/` to the Research Archive and Diagrams & Whiteboards pages.
5. Create the databases described in `02-NOTION-DATABASES.md` if you want live status tracking.
6. Use `03-ATTACHMENT-MANIFEST.md` to upload and place every report, research file, screenshot and whiteboard export.
7. Keep the generated DOCX/PDF as printable snapshots; the Markdown pages are the maintainable source.

The package intentionally preserves historical reports under `attachments/archive/` while making the new master blueprint canonical.

## Current canonical attachments

Upload everything under `attachments/current/` to the Project Hub or Research Archive. The master DOCX/PDF and final recheck record in that folder supersede the historical files under `attachments/archive/`.
