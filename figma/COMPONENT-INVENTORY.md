# Component inventory

## Foundations

Icon, type styles, color variables, spacing, radius, shadows, focus ring and motion.

## Navigation

App rail, nav item, section header, breadcrumb, command palette, tabs and context switcher.

## Inputs

Button, icon button, text field, search field, select, checkbox, radio, switch, slider, number input, file picker and page-range field.

## Document

Drop zone, file row, page thumbnail, page selection badge, document tab, canvas toolbar, zoom control, crop handles, annotation handles and comparison scrubber.

## Job and feedback

Locality badge, status chip, progress row, job tray, alert, inline validation, toast, empty state, error state, result summary and verification checklist.

## Containers

Card, inspector section, accordion, modal, sheet, popover, context menu, split panel and resizable divider.

Each component requires: default/hover/focus/pressed/disabled/error/loading states, light/dark/high-contrast variables, keyboard behavior and accessible name guidance.
