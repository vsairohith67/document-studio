# Figma plugin plan

- Tokens Studio: token source/sync.
- Iconify: icon exploration; choose a single production icon family and verify its license.
- Design Lint: missing styles and inconsistent values.
- Accessibility checker: contrast, labels and focus/interaction review.
- Autoflow or equivalent: flow diagrams only.

Do not install many plugins into the production design process. Every plugin adds maintenance and provenance risk.
